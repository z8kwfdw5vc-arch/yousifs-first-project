## Description
a simple game with a moving target whitch the user got to click it and get a higher score, like makeing a competiton to get the higher score its depinding on reflection and how fast the player can go
## User Stories
*As a user i want to click the start botton to start the game.
*As a user i want the target to change the position randomly and catch many of it
*as a user my score to incris after every time a catch the target
*as a user i want the game to stop automaticly when the time hits zero(0)
as i user i want a reset button to clear everything and start a new game
